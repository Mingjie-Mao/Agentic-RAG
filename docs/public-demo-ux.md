# 公开演示与项目展示

公开首页介绍业务场景、架构与评测边界，`/live` 提供受限访客体验，`/replay.html` 查看真实历史执行。回放文件含录制时间、模型身份和实际事件，全部使用自建虚构语料；不能当作实时执行、正式 Core 评测或动态策略效果证明。

## 访客身份

`POST /api/auth/visitor` 仅在 `demo_mode` 和 `trial_mode` 同时开启时可用。服务端建立独立的稳定 member 身份，不接收客户端指定的账号、租户或组，不继承原支持账号的文档所有权，不允许继承 admin。使用现有 HttpOnly / SameSite cookie 会话、工具鉴权与只读检查。访客共享每天的额度（UTC 零点重置）；换浏览器或重新进入不会重置额度。

原账号登录保留供本地组织测试使用，公开 `/live` 不显示账号和密码。

进入只读演示的会话请求有 15 秒客户端超时，超时后提示重试或查看真实执行回放。重新进入不会重置共享额度。

Pages 在公开 HTTPS 响应中为会话 cookie 补充 `Secure`，保留后端的 HttpOnly / SameSite 与有效期，并分别处理每条 Set-Cookie；本地 HTTP 调试仍使用原配置。实现直接使用 [Cloudflare Headers 官方 API](https://developers.cloudflare.com/workers/runtime-apis/headers/)，不改会话身份、权限或预算。

## 等待与取消

四个问答入口始终可重新展开，点击只填入问题，发送才开始执行并计额度；入口说明核对引用、年份政策差异、资料冲突和依据不足拒答。权限对照链接指向固定虚构角色的历史快照，不改变当前访客身份。

问答继续走原 `/api/chat`。`X-Chat-Request` UUID 将一次请求与 `/api/chat/progress/{id}` 的 UI 遥测关联；阶段直接来自检索、生成、校验与最终鉴权代码。遥测按租户和用户隔离，不含问题、文档标题或原文，最多保留 256 条、15 分钟。它不调度执行，不替代 LangGraph，也不提供通用检查点。当前单进程部署可使用；多进程部署前需要接入共享遥测存储。

“停止等待”只断开客户端等待，不声称取消后端模型调用。页面继续查询状态，已完成结果通过原历史接口重新鉴权后取回。连接中断、状态过期和较长等待都明确说明结果未知；已预留访客额度不退回，重试另计额度。Agent 取消复用原取消接口与执行预算检查，在执行边界生效。

经过秒数独立于网络轮询，每秒更新。原 HTTP 请求等待 120 秒后，客户端停止等待并继续查状态；该时间不是服务端模型超时。阶段和恢复结果查询有 8 秒网络超时，引用加载有 15 秒超时；失败引用可重新加载并再次鉴权。额度耗尽时提供无需模型请求的回放入口。

近期耗时取当前账号最近 20 个仍有权查看的真实回答；无样本显示未测，不能填入估计数。Agent 时间线使用持久化审计事件，只展示已发生的步骤，技术事件保留在展开详情中。

## 资料与测试隔离

网页验收上传由测试 fixture 在成功或失败后软删除。`scripts/cleanup_browser_uploads.py` 默认只读检查，`--apply` 只匹配固定测试标题、支持账号所有权及 `UI-S1-OK` / 虚构验收文档双标记。保留原文件、历史报告和数据库审计。

新建上传成功后立即把 document_id 写入 `.runtime/browser-uploads/` 的原子收据，不保存 cookie 或密码；重复识别返回的已有文档不登记为本测试新建。进程被强制结束、来不及执行 teardown 时，下次网页测试 setup 会按收据恢复软删除。收据清理仅匹配支持测试账号所有、私有、非 seed 文档；原件与版本仍保留。收到上传响应之前被杀死的窗口无法留下收据，旧 Markdown 验收资料仍可通过双标记清理；不声称能覆盖任意进程中断。

引用高亮只使用当前答案绑定的原句，不合并其他历史回答。格式化阅读复用 [react-markdown 官方组件](https://github.com/remarkjs/react-markdown) 与 remark-gfm，保留原文文本切换；不启用原始 HTML 执行，维持默认安全 URL 转换。

## 发布与离线备用

运行 `scripts/publish_live_page.sh <当前 trycloudflare HTTPS 地址>`。发布会构建前端，将应用壳、PDF 阅读器、字库、首页和回放部署到 Pages；API 仍通过现有 Tunnel 访问本机，权限与预算仍由后端执行。

首页历史表格由 `scripts/prerender_site.py` 从原 `site/data.json` 在构建时写入 HTML，不依赖浏览器 JS 或二次请求。Core 正式结果仍为 pending，历史指标在历史详情中，未改写任何评测产物。当前最新构建信息保存到 `release.json`。

录制新回放使用 `scripts/record_public_demo.py --base <本地服务地址>`，新建时间戳文件，不能覆盖已有录制；采集先验证引用只能来自虚构 seed 文档。权限对照是预置虚构角色的实际 `can_read` 快照，不授予实时用户切换身份的能力。
