# Slot generation implementation plan

> **For agentic workers:** Use superpowers:subagent-driven-development and test-driven-development. Execute after evidence selection reviews and replay; current directory is authorized. Do not commit, push, change defaults, read Core or use gold in generation.

**Goal:** Measure production-contract handling separately from a conservative new ordinary-slot generation policy.

**Architecture:** Preserve the direct generation control and reuse `contract_generate` for the shared-contract control. Add an explicit ordinary policy that renders complete, unique, directly scoped literal slot values; unknown text slots use one existing model call with the complete question checklist. Conditions, comparison and history remain owned by the existing contract. Slot traces distinguish literal support from a model checklist and never equate keyword coverage with correctness.

**Tech Stack:** Existing Pydantic answer models, task contracts, source aliases, cumulative ExecutionBudget.
