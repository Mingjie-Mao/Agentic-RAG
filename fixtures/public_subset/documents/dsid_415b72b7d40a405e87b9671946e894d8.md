introduce-session-decorator-to-simplify-cross-sdk-streams-and-credential-rotation

Context: Multiple SDKs exposed slightly different streaming iterator ergonomics and credential refresh hooks which made cross-language examples and platform integrations brittle. This PR introduces a lightweight SessionDecorator abstraction and a small set of shared semantics (ResumeToken v2 + telemetry markers) to harmonize behavior across Python/TypeScript/Go. Goal: make stream consumers simpler to implement, provide a single place for automatic credential rotation and graceful resume, and add telemetry points to measure reauth/backpressure heuristics.

What this changes (high level):
- Add SessionDecorator (py/ts/go) that wraps an existing stream handle/iterator and: automatically refreshes credentials on auth failures, exposes a simple resume_token API, and emits telemetry events for: credential_refresh_attempt, credential_refresh_success, resume_attempt, resume_success, resume_fail.
- Introduce ResumeToken v2 semantics: small stable opaque token returned at stream checkpoints; safe to persist short-term for fast reconnection.
- Unify async iterator ergonomics: all SDKs now offer .stream() returning an async/pullable iterator with a single .resume(resume_token) helper. This removes previously divergent push/pull naming.
- Add backpressure hint optional argument (hint: "latency" | "throughput") to stream factory to allow runtime routing optimizations in Dedicated/Hosted.
- Deprecate older streamResume and token-swap callback signatures; provide compatibility shims for one release cycle.
- Bump SDK versions: python -> 0.42.0, typescript -> 1.12.0, go -> 1.7.3.
- Tests: unit coverage for decorator edge cases, integration tests exercising auth rotation against the dev auth-proxy, and cross-SDK interoperability smoke tests.

Implementation notes:
- Python: session_decorator.py implements an async generator wrapper that catches AuthExpired errors, triggers the provided credential_provider.refresh() and retries from a resume_token. Adds small coordination via an async Lock so concurrent reauth attempts coalesce.
- TypeScript: sessionDecorator.ts implements an async iterable class that mirrors the Python contract, exports a withSessionDecorator factory that preserves stream typing.
- Go: session_decorator.go adds a StreamDecorator type with Resume(ctx, token) and Start(ctx) iterator model; uses channels to translate push->pull where necessary.
- Telemetry: lightweight events emitted to existing "sdk.stream" namespace with fields: event_type, sdk_lang, duration_ms, error_class. These are instrumented behind a toggle so customers can opt into increased telemetry retention.
