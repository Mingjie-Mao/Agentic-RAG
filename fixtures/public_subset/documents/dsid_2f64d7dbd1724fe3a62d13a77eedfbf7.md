behavioral alert sandbox and autotriage hypothesis engine

Summary: Adds a sandboxed runtime and a lightweight hypothesis engine to the incident-bot stack that synthesizes candidate root-cause hypotheses from alert footprints and on-call annotations, executes non-invasive diagnostic playbooks in an isolated environment, and surfaces ranked remediation hints. Motivation: On-call teams spend time triaging noisy signals and validating hunches manually. This change automates hypothesis generation and safe, reproducible diagnostics to reduce time-to-first-action and increase confidence for low-risk mitigations. Design: - Behavioral Alert Sandbox: containerized ephemeral runner that replays relevant metrics/log snippets and executes read-only probes (synthetic queries, trace lookups, config validations) against a copy of sanitized telemetry. Runs in a constrained gVisor/Firecracker environment with strict egress policies. - Autotriage Hypothesis Engine: rule + model hybrid that produces short hypotheses (cause -> mechanism -> likely fix) ranked by confidence and cost-to-verify. Uses a small ensemble of lightweight models (decision trees + logistic regressors) trained on past incidents and augmented by deterministic rules for low-likelihood but high-risk signals. - Silence Smartening: adaptive suppression windows that consider hypothesis confidence and responder load; instead of uniform backoff, silences can be shortened/extended automatically based on observed remediation progress signals. - UX: a compact Runbook Sandbox panel in the incident-bot UI with a one-click "Run Diagnostic" button, hypothesis list, and executed playbook logs. Safety: All sandboxed diagnostics are read-only by default; write-capable playbooks require explicit escalation and 2FA confirmation from an approver. Audit logs and signed attestations are recorded. Migration & rollout: feature gated behind incident-bot feature-flags with Canary -> 20% -> 100% rollout. Defaults off for existing workspaces; opt-in for Beta customers. Test plan: unit tests for hypotheses ranking, integration tests for sandbox orchestration, e2e on a synthetic incident harness.
