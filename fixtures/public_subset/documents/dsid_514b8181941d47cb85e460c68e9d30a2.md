hackathon-2025-inference-ui-demo

Motivation: lightweight hackathon project to build a minimal interactive demo that visualizes inference internals (batching, KV cache hits/misses, token throughput) and exposes a live-coded frontend that can replay sample requests. This PR introduces a small Next.js front-end, a mock serverless backend that simulates Redwood's batching behavior for demo purposes, and simple instrumentation endpoints that surface synthetic metrics. The goal is a portable demo that teams can run locally or in a short demo environment to explain inference tradeoffs. Changesets: added frontend pages and components under /demo-ui, a tiny express-compatible demo server under /demo-server, a scripts/serve-demo.sh helper, and a README with run instructions and screenshots. Checklist: - [x] demo UI with token stream playback - [x] mock batching simulator with configurable batch size/latency - [x] instrumentation endpoints (json) for KV cache stats - [x] runbook in README for local demo and deploy to Vercel - [x] basic accessibility/keyboard nav on UI Notes on fidelity: this intentionally uses a mocked runtime (no real model weights) to keep the demo lightweight; it simulates latency, batching, and KV cache signals deterministically. This is a hackathon artifact intended for internal demos, teaching, and outreach; not production code. Related work: references a few Linear tickets for follow-ups and a separate redwood/examples repo demo (links in README).
