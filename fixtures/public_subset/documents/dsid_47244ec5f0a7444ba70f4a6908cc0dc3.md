runtime: integrate FP8 attention kernel behind feature flag

Summary: Wires the new FP8 attention kernel path into the serving runtime behind a feature flag, adds kernel-registry entries for supported GPU SKUs, and includes basic correctness tests to ensure safe rollout in the FP8/INT8 benchmarking sprint.

Motivation: As part of the FP8/INT8 kernel benchmarking sprint (ENG-7423), we want to evaluate quantization-friendly attention kernels under realistic prefill/decode mixes without risking global regressions. This PR introduces an opt-in dispatch path with explicit guardrails and a clean fallback to the baseline attention implementation when unsupported.

What’s included: (1) Feature flag: adds `runtime.kernels.fp8_attention.enabled` (default: false) and a per-model override hook used by perf-canary cohorts; (2) Kernel registry/dispatch: registers the FP8 attention kernel variant for H100 (SM90) with shape constraints and runtime checks, and routes eligible attention ops to FP8 when the flag is enabled; (3) Guardrails + fallback: validates alignment constraints (head_dim, qkv strides), mask support, and min/max sequence-length regimes; falls back to baseline attention if any constraints are not met, or if CUDA / driver capabilities are insufficient; (4) Correctness tests: adds a small set of deterministic unit/integration tests comparing FP8 attention outputs to the baseline within tolerance across a few representative shapes (single-batch and small-batch, masked and unmasked). These tests are not performance tests; they are intended only to catch blatant numerical/correctness failures.

Out of scope: no heuristic auto-selection logic (will land in a separate PR tied to ADR-019); no scheduler changes; no canary gating logic. This PR is solely the wiring so we can start measuring.

Implementation notes: - This uses a runtime-level kernel-mode selector with explicit tagging for observability; when enabled, metrics include `kernel_mode=fp8_attn` at the op-level to aid perf triage. - Support is restricted to H100 initially. A100 is intentionally excluded in this PR due to incomplete coverage and higher regression risk; enabling on A100 requires additional kernel variants and validation.

Testing: - `runtime-kernels-unit` (CPU) - `runtime-gpu-smoke` (H100) - Added `fp8_attention_correctness_test` suite gated to run only on H100 CI runners - Manual: ran microbench sanity for 3 shapes (see internal note in ENG-7423)

Rollout plan: Default disabled. Perf team can enable via flag for benchmark harness runs and later canary cohorts (handled elsewhere).
