Modernize CI by replacing legacy bash pipelines with composite actions and plugin hooks

Motivation: The monolithic bash pipelines under .github/workflows and scripts/legacy-ci.sh have become brittle and hard to iterate on across services. This PR modernizes the pipeline by introducing reusable GitHub composite actions, a plugin hook system for per-repo policy, and a small cross-platform ci-toolbox binary to compute robust cache keys and talk to the remote cache store. Scope: 1) Add .github/actions/checkout-composite, test-shard-composite, lint-runner-composite. 2) Replace repo-level shell orchestration with composite action calls and a dynamic matrix generator (tools/ci/matrix-gen.js). 3) Remove scripts/legacy-ci.sh and in-repo Docker-in-Docker usage; use buildah/kind where needed. 4) Add ci-toolbox (tools/ci-toolbox/main.go) used by composite actions for cache keying and fast retries. 5) Add .github/ci-config.yml with opt-in staged rollout flags for teams to adopt incrementally. Checklist: - [x] Add composite actions and document inputs/outputs - [x] Implement matrix generator and update matrix shapes - [x] Port lint/test usages to new composites - [x] Add ci-toolbox with basic cache key and remote fetch - [x] Add integration CI job that runs composites end-to-end on a canary subset - [x] Remove legacy script invocations and update README-ci.md Migration notes: The new composites are backward-compatible by default and live alongside legacy workflows during a 2-week canary. Owners can enable ci-config.yml flags to opt into new flows. Rollback is as simple as switching the workflow reference back to legacy scripts if an issue is detected. Risks and mitigations: Cache-key changes may cause cache misses on first runs; ci-toolbox includes a dry-run mode to preview keys. Matrix reshaping can increase pipeline concurrency; we added a default concurrency limit and a dynamic shard sizing heuristic. Future work: Add telemetry hooks to Redwood Console for per-route CI latency and cost, and introduce a GH App to enforce team opt-ins.
