Introduce traffic-modal sampler and fallback lease for robust canaries

Motivation: Production canaries have been brittle when traffic composition shifts between distinct user-modalities (short chat vs long form vs embeddings-heavy). Small shifts create large variance in latency fingerprints causing false positives or noisy rollbacks. This PR implements a traffic-modal sampler that stratifies probe traffic by inferred request modality, applies per-modal baselines, and introduces a lightweight fallback lease protocol for staged rollouts to avoid noisy rapid rollbacks. Design summary: 1) Traffic-modal sampler: a low-overhead classifier (heuristic + fast regexes + small feature hash) tags probes into modalities: short-chat, long-chat, embeddings, reranking. Sampler maintains running windows per-modal and emits stratified probes to the canary evaluator. 2) Per-modal baselines: baseline statistics (p50/p95/p99, throughput) are tracked independently and fused via an ensemble smoothing layer to produce a single canary decision that respects modal imbalance. 3) Fallback lease: when a canary triggers a rollback candidate, the lease protocol holds the candidate in a "quarantine" tier for a short lease window to gather corroborating modal signals before actuating immediate rollback. The lease supports forced-expiry by SRE and auto-extension when signals remain ambiguous. Key benefits: reduces false positive rollbacks during traffic-mode shifts, improves signal-to-noise on p95/p99, and allows controlled staged recovery when anomalies are transient. Implementation notes: - Core sampler implemented in perf/canary/sampler.go with a minimal in-process classifier to avoid cross-service calls. - Baseline engine added to perf/canary/baseline.go, using exponential decay windows and modal-weighted fusion. - Lease state machine implemented in operator/rollout/lease_controller.go; operator annotations allow per-deployment lease tuning. - New metrics: canary.modal.{modal}.latency_p95, canary.lease.state, canary.modal.sample_rate. - E2E tests: perf/canary/test/integration_modal_sampler_test.go simulates multi-modal traffic shapes with synthetic sequenced traces. - Docs: docs/perf/traffic-modal-sampler.md describes config knobs and recommended modal definitions. Rollout plan: 1) Canary enabled behind feature flag true by default in staging. 2) Gradual rollout to 10% of clusters for 48h, monitor per-modal false-positive rate and rollback frequency. 3) Enable fallback lease globally after 7 days if metrics stable.
