Graceful DR activation with operatorless switchover (Terraform + Helm)

Motivation: Provide a deterministic, low-ops path for cross-AZ / cross-region DR activation that does not rely on a long-lived Kubernetes operator. Some customers run in constrained environments where background operators are undesirable; this PR introduces an operatorless switchover flow that uses Terraform to orchestrate infra-level failover and a lightweight helm hook + one-shot scripts to perform application-level state transitions. Key goals: deterministic activation ordering, safe read-only probes before cutover, reversible staged traffic siphon, and clear runbooks-as-code for drills and audits. Changes include a new terraform module (dr/activation-orchestrator) for region fencing and DNS cutover, a helm chart sub-template (charts/private-installer/templates/dr-switchover-job.yaml) for one-shot application migration steps, and a small set of idempotent shell helpers (installer/scripts/dr-heartbeat.sh, installer/scripts/siphon-traffic.sh) for heartbeating and staged connection draining.
