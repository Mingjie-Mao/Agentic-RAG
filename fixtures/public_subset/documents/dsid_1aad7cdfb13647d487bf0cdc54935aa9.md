Add intake lease (onboard lock) and 'changeframe' release composer for concise changelogs

Background: Automated onboarding pipelines and the autosynth release worker occasionally collided when multiple intake jobs touched overlapping model metadata and performance profiles. This caused duplicated changelog fragments and rolling back of in-progress profile calibrations. Motivation: introduce a lightweight coordination primitive (intake lease) and a compact, auditable change representation (changeframe) so the pipeline can safely compose a single, human-friendly release note. What this PR does: 1) intake lease: - Adds a lease-based locking API to the intake service (POST /intake/v1/leases) and a short-lived DB-backed lease store to prevent concurrent release composition for the same model alias/version. - Leases are fair (FIFO) with a configurable TTL (default 30s) and an explicit renew endpoint used by long-running calibrations. - CLI and onboarder hooks now acquire a lease before performing operations that trigger changelog generation. 2) changeframe: - Introduces a normalized changeframe payload (compact JSON) that captures: semantic deltas for metadata fields (license, owner, tags), profile diffs (latency P50/P95 deltas, quantization hints), and example-level sample excerpts used by the release summary generator. - Small binary-safe sample blobs are referenced by content-hash and stored in the probe artifact store to keep changeframes compact. 3) release weaver: - Implements an automated release composer that consumes changeframes and the lease to synthesize a single merged changelog snippet. The weaver deduplicates overlapping profile changes, attaches provenance, and ranks entries by impact score. 4) Additions to the intake CLI: - `rmdrc onboard --draft-release` generates a preview changeframe and uploads it to /intake/v1/preview. 5) Migration & compatibility: - Adds a migration to add leases table and a compatibility shim so older release workers ignore unknown changeframe fields. Rollout plan: staged rollout behind feature flag: intake.leases.enabled; default off. Canary the weaver on the internal model-registry team for two weeks before enabling org-wide. Related: ENG-4281 coordinates with the autosynth release worker rewrite. NOTE: This description is one continuous string per repo conventions.
