Micro-tile cascade attention with rotary hybrid-fuse and adaptive KV throttling

Context and motivation: Our production traces show two pain points: (1) throughput drops and kernel inefficiency for long sequences when attention tiling is coarse-grained; (2) KV cache eviction storms when bursts of diverse contexts force eviction/rehydration cycles, increasing tail latency. This PR implements a new micro-tile cascade attention path and a lightweight adaptive KV throttling policy to address both issues while preserving correctness of rotary/rope encodings.

What this change does: Implements a micro-tile cascade algorithm that splits large sequence attention into small micro-tiles (64-256 token tiles) and composes results with a cascade scheduling pass. The implementation introduces a hybrid-fuse operator that fuses rotary pre/post transforms into the micro-tile kernel to avoid extra memory passes. To prevent eviction storms we add an adaptive KV throttling controller that limits concurrent cache allocations per-request batch and prefers prefix reuse affinity when allocating slabs. Scheduler heuristics are extended to prefer continuous-batching windows for interactive workloads (reduce batching variance) and to fall back to existing flash-attn paths for very short sequences.

Compatibility and runtime flags: The new path is behind two config flags: runtime.attn.microtile_enabled (default: true on dedicated/private builds) and runtime.kv.adaptive_throttle (default: true). No public API changes. Models and operator semantics unchanged — rotary/RoPE is preserved via fused transforms, but we also add an opt-in rotary-offset-snap for models with nonstandard rotations (controlled by model.config.rotate_mode).

Benchmarks (internal lab, p4d-24/96GB):
- Seq=512, batch=8: throughput +18% (tokens/sec) vs current main; p95 latency -11%
- Seq=1024, batch=4: throughput +22%; p95 latency -16%
- Seq=2048, batch=2: throughput +28%; p95 latency -21%
- Bursty mixed-length synthetic workload: 15-40% reduction in tail latency for 99th percentile under concurrency spikes.
