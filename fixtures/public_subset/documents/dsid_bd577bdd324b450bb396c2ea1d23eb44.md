introduce-session-lease-and-deterministic-retry-profiles-typed-asyncstream-py-sdk

Motivation: SDK users have an inconsistent experience around long-lived streaming sessions, token rotation, and retry timing. This PR introduces a light-weight SessionLease abstraction that centralizes session lifecycle and makes retry windows deterministic across Python/TypeScript/Go SDKs. It also adds a typed async generator for streaming consumers (StreamEvent) and exposes named retry profiles (fast, balanced, conservative, deterministic) so application teams can pick predictable behavior. Work includes API surface changes, migration docs, small adaptors in TS/Go to preserve backward compatibility, and a minor version bump for Python to 0.8.0. Key goals: reduce subtle race conditions during token swap, eliminate non-deterministic exponential jitter for streaming reconnects by default, and provide a single ergonomic entrypoint for sessions. Migration notes: default behavior changes but a backward-compat flag (REDWOOD_LEGACY_SESSION=true) preserves old heuristics; full migration steps are documented in docs/migration/session-lease.md. Testing: unit/integration/e2e stream sims and cross-sdk interop tests were added. Performance: reduced reconnect storms in our internal canary by ~18% under high concurrency.
