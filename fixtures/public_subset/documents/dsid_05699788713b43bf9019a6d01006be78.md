Introduce cohort fingerprinting and concise release-note drafter

Motivation: teams onboarding models need compact, stable release notes plus reproducible sample cohorts for targeted performance calibration. This PR adds two coordinated pieces: (1) a cohort fingerprint generator that produces stable cohort ids from sampled probe outputs and dataset seed metadata, and (2) a concise release-note drafter that synthesizes short machine-readable + human-friendly release briefs from profile diffs and cohort-level impact metrics.

What this delivers: a reproducible fingerprint used to tag profiling runs and to group telemetry by cohort; and an automated release-note writer that consumes profile deltas, sample cohort summaries, and a template bank to create brief, reviewer-ready release notes for model onboarding. The drafter favors one-line impact statements and a short bulleted summary optimized for engineering change logs.

Changes included (summary): bump profile schema to v1beta3 (backwards compatible with migration path), add cohort_fingerprint module (python), add release_drafter CLI and a templating hook for onboarding pipelines, integrate cohort ids into the profile manifest and the telemetry export schema, add unit/integration tests and a small end-to-end example in examples/registry/drafter_demo.

Notes on compatibility and migration: profiles now include an optional "cohort_id" field; older profiles without cohort_id are supported by the loader (it will generate a transient fingerprint when reading). The schema bump is additive (v1beta2 -> v1beta3); we include an automated migration script that annotates existing manifests in-place with cohort_ids using historical seeds when available.

Security/privacy: cohort fingerprints are derived deterministically from hashed non-sensitive metadata and sampled evaluation outputs; we deliberately avoid including customer identifiers or raw inputs in the fingerprint. The migration script can be run with --dry-run and supports a redaction flag for orgs with stricter policies.
